IRON Android V5.3 – Appwrite Images + Smart Plans

Bilder:
- Sprachbefehl: "IRON, zeig mir Chevalier Roth Logo"
- Android sucht NICHT zuerst lokal, sondern ruft /api/images/search der Appwrite Function auf.
- Erwartete IDs: database iron, table iron_images, bucket iron-images.
- Function v2.5 Images muss deployed sein.
- Bild erscheint im HUD; Antippen öffnet Viewer mit +, -, X.

Smart Plans:
- Kombinierte Wünsche nach Plan + Einkauf/Material werden als ein Projekt erzeugt.
- IRON erstellt einen Hauptplan und separate Einkaufs-/Materiallisten pro Element.
- Funktion ist allgemein und nicht auf Protein-Gerichte beschränkt.
- Beispiel: "Mach mir einen Plan für 3 Gerichte pro Woche mit mehreren Proteinquellen,
  jeweils mit Einkaufsliste und Zubereitung."

Bestehende Funktionen (Memory, Cloud Voice, News, Wetter, Aktien, Shopping) bleiben erhalten.
